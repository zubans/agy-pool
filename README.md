# agy-pool
agy-pool — пул аккаунтов Antigravity CLI — Самостоятельный сервис: принимает запросы «промпт → ответ модели» и выполняет их через Antigravity CLI (agy) по подписке Google, распределяя работу между несколькими аккаунтами.
